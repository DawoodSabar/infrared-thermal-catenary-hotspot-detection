# Research on Infrared Thermal Imaging Sensor for Overhead Catenary Hot Spot Detection

MATLAB-based simulation framework for infrared thermal imaging and hotspot detection in overhead railway catenary systems. 


# Overview 
This repository presents the simulation implementation accompanying the research on infrared thermal imaging-based hotspot detection for railway overhead catenary systems. The work focuses on thermal anomaly analysis, temperature monitoring, and simulation-based evaluation of hotspot detection performance.
